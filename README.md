# Focus Yoga Zuk Courses

Репозиторий учебных материалов и ZIP-курсов для Focus Yoga Zuk. Вопросы и ответы предназначены для самостоятельного изучения и подготовки к собеседованиям: HTML, CSS, JavaScript, TypeScript, React, frontend-инструменты, браузеры, сети, безопасность, архитектура, алгоритмы, ИИ, дизайн и HR.

Это репозиторий материалов: для чтения Markdown и использования готовых архивов сборка проекта не требуется.

## Структура проекта

- [questions.md](questions.md) — общий список вопросов, сгруппированных по темам и разделам.
- [answers/](answers/) — исходные ответы с пояснениями и примерами кода. Обычно каждая тема хранится в Markdown-файле `title--subtitle.md`, например `html--основы-и-семантика.md`.
- [courses/](courses/) — готовые ZIP-курсы для импорта в Focus Yoga Zuk
- [.agents/](.agents/) — проектные скилы для ИИ-агента: инструкции по подготовке ответов и сборке курсов. Каждый скил содержит точку входа `SKILL.md` и подробный промпт.
- [artifacts/](artifacts/) — рабочие результаты сборок, сгруппированные по наборам курсов: отдельные `manifest.json` и `questions.json` для проверки, снимки каталога, отчёты `report.json` и `report.md`. Здесь также находятся два Python-скрипта `build_courses.py` для отдельных наборов тем.

## Подготовка материалов и курсов

1. Выберите темы или вопросы из `questions.md` либо подготовьте отдельный список.
2. Запустите `$qa`, указав нужные темы или вопросы. Скил сначала распределяет вопросы по тематическим разделам `questions.md` без дублей, затем создаёт или обновляет ответы в соответствующих файлах `answers/`. Существующие вопросы и ответы сохраняются.
3. Проверьте подготовленные ответы: формулировки вопросов, техническую точность, примеры и отсутствие пропусков.
4. Запустите `$course`, указав нужные курсы или файлы из `answers/`. Скил проверяет существующие ZIP в `courses/`, создаёт новые курсы или обновляет найденные и предоставляет JSON для проверки. После подготовки ответов сборка ZIP запускается отдельным шагом по запросу пользователя.
5. Проверьте итоговые архивы и отчёт сборки перед добавлением изменений в Git.

Инструкции скилов:

- [`qa`](.agents/skills/qa/SKILL.md) — распределение вопросов по темам в `questions.md`, подготовка и обновление ответов в `answers/`; [подробный промпт](.agents/skills/qa/references/prompt.md).
- [`course`](.agents/skills/course/SKILL.md) — создание и обновление ZIP-курсов; [подробный промпт](.agents/skills/course/references/prompt.md).

## Формат ZIP-курса

Один архив содержит один курс. Файлы располагаются в корне ZIP, без дополнительной папки-обёртки:

```text
manifest.json
questions.json
assets/           # при наличии изображений
```

- `manifest.json` — метаданные курса: версия схемы, ID, версия курса, маркер ревизии `hash`, название, описание, теги и необязательная иконка.
- `questions.json` — плоский массив вопросов с ответами в JSON
- `assets/` — изображения, на которые ссылаются данные курса.
